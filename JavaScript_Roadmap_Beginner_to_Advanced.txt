============================================================
HOW TO USE MDN
============================================================

1. LEARN — MDN JavaScript Guide
Use the JavaScript Guide for structured learning.

2. LOOK UP — MDN JavaScript Reference
Use the Reference when you need exact details about:
- Methods
- Objects
- Operators
- Statements
- Language features

3. PRACTICE — MDN Learn Web Development
Use MDN's learning tutorials and challenges for hands-on practice.

Do NOT try to read the entire JavaScript Reference from beginning to end.

Recommended approach:
Guide -> Practice -> Reference when needed
